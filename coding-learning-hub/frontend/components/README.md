# Frontend Components

Komponen saat ini dirender oleh `frontend/js/app.js` agar frontend tetap dependency-free dan mudah di-hosting sebagai static website.

Saat platform berkembang ke React, folder ini disiapkan untuk memecah komponen seperti:

- `RoadmapCard`
- `ReferenceItem`
- `QuizPanel`
- `PlaygroundEditor`
- `ProgressBar`
- `Modal`
